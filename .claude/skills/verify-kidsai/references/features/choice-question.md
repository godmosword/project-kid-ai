# 選擇題

每個單元的第 1 關是一題有答案的選擇題：點點念題目，孩子點一個選項就作答。答對時選項打勾、點點念成功句；答錯時那個選項變淡、不能再點，點點說「再試一次」的話；錯到上限（2 次）就揭曉正解並打勾。第 1 關的選項如果有聲音（單元 1、2），每個選項是一整列，右邊另有重聽鈕；選項聲音開始播放時，卡上會顯示聲音裡的話。8 秒沒動作，點點會給提示；計時從題目和選項的初始旁白念完後開始。單元 1 另有第 2 關「箱子猜猜看」：一樣是點一個選項就作答，但這題沒有正解——孩子點的那個標成「你選的」，其他選項不變淡、也沒有打勾，點點念揭曉句後出現「下一步」。

## Sub-features

- `choice-answer`：點選項即作答；答對打勾＋成功句，出現「下一步」。
- `choice-retry`：答錯的選項變淡、不能點，點點說再試一次的話（第一次錯不揭曉）。
- `choice-reveal`：錯到上限（2 次）揭曉正解並打勾，出現「下一步」。
- `choice-sound`：有聲音的選項（單元 1「家人／電子玩具／AI」、單元 2「小熊說／小兔說」）：一整列＋重聽鈕；選項聲音開始播放時，卡上出現聲音裡的話。
- `choice-hint`：8 秒沒動作，點點的框出現提示。
- `choice-box`：沒有正解的選擇題（單元 1 第 2 關）：上方有舞台圖（箱子只露一小角），孩子點的選項標成「你選的」，其他選項不變淡、沒有打勾；揭曉句之後出現「下一步」。

## How to get to it (user POV)

- 各單元的第 1 關（`--beat 1`）：開場念完按「下一步」就到。
- 單元 1：「聽一聽，誰說『我猜』？」（正解 AI）；單元 2：「誰說得比較清楚？」（小兔說）；單元 3：「哪張怪怪的？查一查」（第二張）；單元 4：「誰來決定結局？」（我）。
- 單元 1 第 2 關（`--unit 0 --beat 2`）：第 1 關答完按「下一步」就到。題目「你猜箱子裡是什麼？」、上方舞台圖、三個選項（貓咪／小車／香蕉）。

## Driving it with control-kidsai

Preconditions:

- baseline；`doctor` 通過；要真實點擊時先 `build --for-testing`（見 SKILL.md 的 Drive）。

- **看題目（前置狀態）。** `launch --unit 0 --beat 1`。看得到：題目「聽一聽，誰說『我猜』？」、三列有聲音的選項（家人、電子玩具、AI），每列右邊有播放鈕。
- **答錯一次再答對（choice-answer、choice-retry）。** 真實點擊 `option.family` → `option.ai`。`run new --feature choice-question --entry answer`，`record --flow choice-answer --run $RUN`。看得到：點「家人」（橘框）→ 家人變淡、點點框「再聽一次，誰說『我猜』？」→ 點「AI」（橘框）→ AI 打勾、點點框「對！AI 常常用猜的。」、下方「下一步」。
- **揭曉（choice-reveal）。** 真實點擊 `option.family` → `option.toy`（都答錯）。`run new --feature choice-question --entry reveal`，`record --flow choice-reveal --run $RUN`。看得到：「家人」變淡；點「電子玩具」後錯到上限，它標成孩子選的（不變淡），「AI」打勾、點點說「是 AI，它說「我猜」。」，出現「下一步」。
- **箱子猜猜看：沒有正解（choice-box）。** 真實點擊 `option.cat`（前置只用 `--unit 0 --beat 2` 準備所在關卡）。`run new --feature choice-question --entry box`，`record --flow choice-box --run $RUN`。看得到：舞台圖「箱子只露出一小角，看得到尖尖的耳朵」在畫面上、三個選項都可點 → 點「貓咪」（橘框）→「貓咪」標成你選的、「小車」與「香蕉」仍可點且沒有標記、點點框「你和 AI 都會猜，有時對有時錯。」、下方「下一步」。
- **重聽鈕、提示（choice-sound、choice-hint）。** needs-flow：重聽要證明的是聲音；提示要等 8 秒不動，還沒有流程。

## Gotchas

- 第 1 關一開始會依序念選項的聲音，但選項仍可作答；選擇一項會送出答案並中斷目前播放。截圖前等畫面穩定。
- 變淡的選項是 `isEnabled == false`，不是被移除；用 identifier 找得到。
- 8 秒提示計時從題目和選項的初始旁白結束後開始，不是進入題目畫面時開始。
- 回顧題（`--beat 7`）用同一種作答方式，但它是另一個進入點，見 [review-and-sticker](./review-and-sticker.md)；不要拿第 1 關的證據當回顧題的證明。
- 卡上的「聲音裡的話」會在該選項的聲音開始播放時出現；截圖前等三個聲音都播完。
- 第 2 關是「沒有正解」（內容 JSON 的 `scoring: open`）：答錯不變淡、不會出現第二個標記，不要把第 1 關「答錯變淡」的預期套在這一關。
- 選項卡上的圖是裝飾性元素（沒有無障礙標籤），流程只能斷言選項本身；只有第 2 關的舞台圖有自己的標籤（內容 JSON 的 `a11y_label`），所以選項圖換了之後要靠逐張看證據與人工驗收。
