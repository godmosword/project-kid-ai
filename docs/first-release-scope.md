# 首版範圍

更新：2026-10-01。決定由 Michael 定案；改範圍要先改這份，再改程式。Notion 由 Grok 依本檔同步。

## 首版決定（2026-10-01）

| 題目 | 決定 | 理由與之後怎麼走 |
|---|---|---|
| 語音辨識 | 首版**不含**，跟讀維持「一起說」 | 開麥克風屬 L3，裝置端辨識在兒童身上的表現沒有數據。ASR spike 由大人照 [測試步驟](spikes/asr-spike-protocol.md) 並行；依 spike 與試玩結果另案決定。 |
| 進度保存 | 維持 **D30**：只在記憶體，關掉 App 就重來 | 先照現況試玩；若跨天重玩明顯受阻，再提「只存必要進度＋清除方式」的 L3 計畫。 |
| 家長區 | 首版**只有現有家長卡**（貼紙頁「給大人」） | 家長閘、本週摘要、匯出延後；摘要與匯出牽涉事件紀錄與資料傳出，屬 L3。 |
| 裝置與方向 | **只做 iPhone、鎖直向**（2026-10-01） | 所有畫面都是照 iPhone 直向設計的；iPad 只是把手機畫面放大顯示，橫向也沒有設計過，孩子常不小心把手機轉橫。iPad 版面等試玩後再評估。 |

## 首版包含

- 四個島：認識（會猜）→ 提問（說清楚）→ 檢查（看證據）→ 創作（自己決定結局），內容以 `content/units/` v1 為準。
- 系統語音旁白（點點與猜猜帽不同語速／音高），一起說的逐字變色。
- 家長卡（共玩用）。
- VoiceOver、動態字級（到「輔助使用 2」）、減少動態效果。
- 只有本機：不連網、不收集兒童資料（AGENTS.md）。
- iPhone 直向（最小到 iPhone SE）。

## 不在首版

- 語音辨識（麥克風）。
- 進度保存、貼紙本（貼紙本要跨次保存，跟著 D30）。
- 家長齒輪、家長閘、本週摘要、匯出、時間晶片。
- 預錄配音：等配音方式定案（TODOS.md）。
- iPad 專用版面、橫向。
