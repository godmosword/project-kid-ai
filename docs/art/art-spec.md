# 美術規格書 v1

給：用 Codex、Grok 生圖的人（Michael），以及之後把圖放進 App 的工程（Claude Code）。對應路線圖步驟 7。

生圖用的 prompt 見 [generation-prompts.md](generation-prompts.md)；需要哪些圖見 [素材清單](../content-schema-v1-mapping.md#素材清單給路線圖步驟-7)。

## 1. 製作方式與順序

- **工具**：Codex、Grok 生圖，Michael 挑選與核准。
- **順序**（不要跳）：
  1. 風格方向：3 個方向各畫同一組測試圖，Michael 選一個。
  2. 角色定稿：點點、猜猜帽的設定圖。
  3. 地圖首頁。
  4. 單元 1 的 14 張圖（素材清單「單元 1」）→ 放進 App → 找孩子試玩（路線圖步驟 3）。
  5. 試玩沒問題，再做單元 2–4 的 21 張。
- 每一張定稿圖都要記在 [provenance.md](provenance.md)：用哪個工具、哪天、完整 prompt、參考圖。上架審核或被問版權時要拿得出來。

## 2. 生圖紅線

- 不得使用或模仿真實兒童、真人的照片或長相；不得上傳孩子照片當參考圖。
- 不得模仿既有的卡通角色、品牌、吉祥物，也不得在 prompt 裡寫現有作品或畫家的名字。
- **圖裡不放任何文字**（字由 App 疊上去，才能多語系、才能被 VoiceOver 念出來）。
- 不嚇人：不要尖牙、流血、黑暗恐怖、受傷、哭泣特寫、武器。
- 不帶宗教符號、國旗、特定品牌商品。
- 使用前確認 Codex、Grok 當下的使用條款允許商用；條款變了要重看。
- 標「需核准」的圖（素材清單打 ✅）會影響教學判斷，定稿前 Michael 要逐張確認「圖真的表達了題目要的東西」，例如小狗的四隻腳要看得清楚（單元 3 要孩子數腳，四隻腳必須分開、數得出來；App 的暫代圖也照這條畫）。

## 3. 角色

兩個角色**一眼就要分得出來**，因為內容一直在教「點點不是 AI、猜猜帽才是 AI」。

| | 點點（旁白，不是 AI） | 猜猜帽（AI） |
|---|---|---|
| 形象 | 圓滾滾的小機器人夥伴，溫暖、像朋友 | 一頂會說話的魔術帽 |
| 主色 | 珊瑚色 `#F2877A` | AI 藍 `#1E6FC2` |
| 固定標記 | 胸前一個愛心形燈 | 帽子上固定有一塊空白小牌子；「AI」字樣由 App 疊上去（圖裡一律不放字） |
| 形狀語言 | 圓、軟 | 有尖頂、有帽簷，輪廓和點點完全不同 |
| 表情（每個角色都要） | 開心、好奇、指引（伸手指向畫面）、鼓勵 | 猜（眼睛往上看、帽尖一個問號）、不確定、開心、道謝、被抓到說錯（不好意思地笑，不是難過） |

設定圖要有：正面、側面、背面各一張，加上上面的表情，全部透明背景。

## 4. 視覺規格（Figma 與 SwiftUI 共用）

### 顏色

| 名稱 | 色碼 | 用法 | 對比（配字） |
|---|---|---|---|
| bg | `#FFF8EC` | 兒童畫面底色（奶油色） | — |
| surface | `#FFFFFF` | 卡片 | — |
| ink | `#2B2B3A` | 主要文字 | 背景上 13.2:1 |
| ink-secondary | `#5C5C7A` | 次要文字 | 背景上 6.1:1 |
| island-1 認識 | `#F5B82E` 黃 | 島嶼、單元主色 | 配 ink 7.8:1 |
| island-2 提問 | `#3BAA6E` 綠 | 同上 | 配 ink 4.7:1 |
| island-3 查證 | `#F08A3C` 橘 | 同上 | 配 ink 5.6:1 |
| island-4 創作 | `#A98BF0` 紫 | 同上 | 配 ink 5.1:1 |
| action | `#1A7A4B` 深綠 | 主要按鈕（前進、一起說） | 配白字 5.3:1 |
| diandian | `#F2877A` 珊瑚 | 點點 | 配 ink 5.7:1 |
| ai | `#1E6FC2` AI 藍 | 猜猜帽、AI 徽章 | 配白字 5.1:1 |
| parent | `#3D4A5C` 石板灰 | 家長頁（和兒童頁明顯不同） | 配白字 9.0:1 |

- 所有文字對比 ≥ 4.5:1（上表已驗算）。
- **顏色不能是唯一的提示**：選項、分組、狀態都要再有圖形、圖示或文字（例如「留下／要改正」除了顏色，還要有 ✓ 與鉛筆圖示）。
- 失敗不變紅：「再試一次」用中性色，不用紅叉。

### 字

- 使用系統字型（中文為蘋方－繁），支援 Dynamic Type。
- 兒童：金句與題目 34pt 以上、選項 22pt 以上、最小 17pt；每行不超過 12 個中文字。
- 家長頁：內文 17pt、說明 15pt。

### 尺寸與版面

- 兒童可點的東西至少 **60 × 60 pt**（Apple 最低 44pt，孩子手指不準要更大）；選項卡至少 140 × 140 pt。
- 間距用 8pt 格線；圓角 20pt（卡片）、28pt（大按鈕）。
- 一屏一件事，主按鈕只有一個，放在拇指碰得到的下方。
- 支援 iPhone 直向與 iPad；插畫要能在兩種比例下裁切。

### 動態

- 使用 SwiftUI 內建動畫；進出場 ≤ 0.4 秒；支援「減少動態效果」（開啟時改淡入淡出）。
- 慶祝效果不得閃爍（每秒閃超過 3 次）。
- 用第三方動畫套件（Rive、Lottie）要 Michael 在 PR 中同意。

## 5. 圖檔規格

| 類型 | 比例 | 生圖尺寸 | 背景 | 例子 |
|---|---|---|---|---|
| 角色 | 直向 | 2048 px 高 | 透明 | 點點、猜猜帽設定圖 |
| 圖卡（選項、沙盒卡、提示圖） | 1:1 | 1024 × 1024 | 透明或單色 | `img_card_ai`、`img_u3_card_dog` |
| 場景（故事、猜箱子場景、排序圖） | 4:3 | 2048 × 1536 | 完整場景 | `img_box_peek_cat_ear`、`img_u4_rain` |
| 貼紙 | 1:1 | 1024 × 1024 | 透明，含白色描邊 | `img_sticker_can_guess` |
| 地圖 | 3:4 直向 | 2048 × 2732 | 完整場景 | 地圖首頁 |

- 檔名＝內容裡的 key，例如 `img_card_ai.png`；key 以素材清單為準，不要自己取名。
- 生圖原檔與定稿放在 repo 的 `design/art/`（參考用，不打包）；放進 App 時由工程轉成 Asset Catalog，檔名不變。
- 聲音（`sfx_*`）與旁白（`vo/*`）不在這份規格書範圍。
