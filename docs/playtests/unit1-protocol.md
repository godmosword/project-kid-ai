# 單元 1 試玩：步驟

對象：帶孩子試玩的大人（Michael 與家長）。這是找問題用的小樣本試玩，不判定通過或失敗；結果只寫進 [彙總表](unit1-report.md)。

## 本輪要回答的三個問題

1. **操作：** 孩子能不能不靠大人，自己從地圖玩完單元 1（認識島）？
2. **角色：** 孩子分不分得出「點點」（帶路的朋友，不是 AI）和「猜猜帽」（會猜的 AI）？
3. **概念：** 玩完後，孩子能不能用自己的話說出「AI 是猜的」「AI 可能猜錯」？（「可以看圖或問人來確認」是單元 3 才教，有說出來算加分。）

另外順便看：一起說的跟讀節奏、「我不確定」標籤有沒有被注意到、哪裡笑了、哪裡無聊。結果也會用來決定沙盒要不要加「AI 看到的」欄（`docs/first-release-scope.md` 的待決策項）。

## 對象與同意

- 1–2 位 6–8 歲孩子，每位 15–30 分鐘，一次一位。
- 家長事先知道要做什麼並同意，而且全程在場。孩子說不想玩就停。
- 孩子只用代號：C1、C2。不寫名字、學校，也不寫生日，只記年齡（例如「7 歲」）。

## 開測前檢查

- [ ] iPhone 上裝 Debug build（Xcode 選 KidsAI＋那支 iPhone，按 ▶）。
- [ ] 飛航模式、勿擾模式；通知全關。
- [ ] 音量調到孩子聽得清楚；確認系統有中文（台灣）語音，不然旁白沒有聲音。
- [ ] 開「引導使用模式」（設定 → 輔助使用 → 引導使用模式），讓孩子不會跳出 App。
- [ ] 換下一位孩子前：把 App 滑掉重開，進度會回到只有認識島（D30）。
- [ ] 觀察員選單只給大人救場用，用了要記在「介入」欄。打開方式：兩根手指**同時**按住頂列進度點的正上方 3 秒（只有 Debug build 有）。打不開時，長按左上 X 1.5 秒回地圖再重進。
- [ ] 準備一張紙本記錄表（照下面的觀察項），只畫勾和寫短詞。

## 大人怎麼說

- **開場（固定說法）：**「這是一個新遊戲，我想看看你怎麼玩。沒有對錯，玩不懂也沒關係，是遊戲要改。」
- **過程中：** 不提示、不代答、不指螢幕。孩子問「要按哪裡？」時回答：「你覺得呢？」
- **介入：** 孩子卡住超過 30 秒，或明顯不開心時才介入。介入時只說最少的話，並記下是在第幾關、怎麼幫的。
- **收尾三題（照念，不換說法，不追問到孩子說出「正確答案」）：**
  1. 「剛剛那個圓圓的點點，跟戴帽子的猜猜帽，有什麼不一樣？」
  2. 「猜猜帽猜得都對嗎？怎麼知道的？」
  3. 「如果 AI 跟你說一件事，你會怎麼做？」
- **判準（照這個記，不自己加分）：**
  - 「分得出角色」：第 1 題自己說出點點不是 AI，或猜猜帽才是會猜的那個＝是；要大人追問後才點頭＝部分；講反或說不知道＝否。
  - 「AI 是猜的」：第 2 題說出「它用猜的」「它不知道」一類的話＝是；只說「有對有錯」沒提到猜＝部分；說「都對」＝否。
  - 「AI 可能猜錯」：第 2 題說出某一次猜錯了，或「有時候會錯」＝是；要大人提醒哪一題才想起來＝部分；說「都對」＝否。
  - 「想到可以確認」（加分）：第 3 題說要看圖、問大人、再想想＝是；說「聽它的」或不知道＝否。

## 觀察項

每一關記：**自己完成／需要幫忙／放棄**、卡住的地方（短詞）、有沒有笑或抱怨。紙本可以分孩子記，但寫進彙總表時只留合計和共通的觀察。

| # | 關卡（`content/units/unit_1_recognize.json`） | 特別看 |
|---|---|---|
| 0 | 開場 `u1_intro`：點點自我介紹 | 有沒有聽到「我是點點，不是 AI」 |
| 1 | 聽一聽 `u1_gate1_listen`：誰說「我猜」？ | 會不會按重聽鈕；答錯後的反應 |
| 2 | 箱子 `u1_gate2_box`：你猜箱子裡是什麼？ | 看露出的貓耳朵猜不猜得到 |
| 3 | 一起說 `u1_gate3_asr` | 會不會跟著念；要不要再說一次 |
| 4 | 儀式 `u1_gate4_sandbox_ritual`：猜猜帽時間 | 知不知道接下來換 AI 猜 |
| 5 | 沙盒 `u1_gate4_sandbox`：猜猜帽猜、孩子反應 | 有沒有注意到「我不確定」；選「好像對／好像錯／不知道」時有沒有看圖 |
| 6 | 故事 `u1_story`：找襪子 | 分歧選了什麼、懂不懂選擇的後果 |
| 7 | 回顧 `u1_review`：AI 比較像？ | 答對與否、有沒有猶豫 |
| 8 | 貼紙 `u1_sticker`：會猜貼紙 | 喜不喜歡；家長卡讓大人看 |
