# 配音方式：決策表

給 Michael 決定旁白與聲音用哪一種做法（TODOS「決定旁白要用 AI 配音還是真人配音」）。價格與服務條款會變，表裡只寫要查的項目，不寫數字。

## 要配的有哪些

- **旁白 301 段**（`vo/<單元>/…`，目前都是 `tts_placeholder`）。說話的角色有兩個：
  - **點點**：帶路的朋友，不是 AI。
  - **猜猜帽**：AI。
- **聲音卡 9 個**（`sfx_*`）：單元 1 第 1 關家人、電子玩具、AI 各說一句；單元 2 小熊、小兔各一句；單元 3 四句話。它們是「另一個人在說話」，所以要和兩個角色的聲音不同。
- **寫死在程式裡的字**，例如「我不確定」，也要有對應的音檔。

## 現況

App 用 iPhone 內建的語音合成（`AVSpeechSynthesizer`，zh-TW）。兩個角色和每張聲音卡各自調語速、音高（`app/KidsAI/Speech/Narrator.swift`）。「一起說」的逐字變色，用的是系統回報「念到第幾個字」。裝置上沒有中文（台灣）語音時，不出聲，字會一次全部顯示。

## 三種做法

| | A 系統語音（現況） | B AI 語音預錄 | C 真人配音 |
|---|---|---|---|
| **兩個角色分得出來嗎** | 同一個聲音，只差語速、音高，**最可能分不出來** | 可以挑兩個不同的聲音 | 最清楚，可以請兩位配音員 |
| **孩子聽不聽得懂** | 多音字、語調偶爾怪；可以改內容文字來避開 | 通常比系統語音自然；多音字仍要一句一句聽過 | 最好 |
| **溫度、像朋友** | 低 | 中 | 高 |
| **內容改了怎麼辦** | 改文字就生效 | 改到的句子重新產生（可以寫成 pipeline 的一步） | 要再約錄音 |
| **費用** | 0 | 服務費（要查） | 配音費＋錄音室（要查） |
| **逐字變色** | 現成 | 要每個字的時間點（有些服務會給，要查） | 要人工對時間，或用工具自動對齊 |
| **App 大小** | 不變 | 多一批音檔（壓縮後約數 MB） | 同 B |
| **工程** | 不用做 | 預錄旁白接口（L2）：有音檔就播，沒有就退回系統語音 | 同 B |
| **授權與合規** | 無 | 要確認：可商用、可用在兒童 App、不能模仿真人聲音。產生音檔時只送內容文字，不送任何兒童資料；但 pipeline 呼叫外部付費服務屬 L3 | 要簽授權（使用範圍、年限、可否修改） |
| **離線** | 是 | 是（音檔內建） | 是 |

## 建議

1. **單元 1 試玩先用 A（現況）。** 不花錢，內容也還在改。試玩時特別記兩件事（[試玩步驟](playtests/unit1-protocol.md)的「角色」問題）：
   - 孩子靠聲音分不分得出點點和猜猜帽。
   - 有沒有聽不懂的句子。
2. **試玩後依結果決定：**
   - 分得出來、也聽得懂：首版維持 A，省下成本，內容可以繼續改。
   - 分不出來或常聽不懂：**首版用 B**。內容定稿前改句子的成本低；做法是先提 L3 計畫（pipeline 呼叫外部服務），再提預錄旁白接口的 L2 計畫。
   - C 等內容穩定、確定要長期經營再考慮。
3. **不論選哪個，都要先做完 A 能做的改善**：把試玩時聽不懂的句子改寫，多音字換成不會念錯的說法。

## 決定之前要查的

- B：至少比兩家服務。要查的有：zh-TW 兒童向的聲音品質、可商用和兒童 App 的條款、每個字的時間點、費用、資料保留政策（只送內容文字）。
- C：配音費用與時程、兩位配音員的試音，以及授權條款。
